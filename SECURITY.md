# Security Policy

## Scope

This profile repository contains public-facing profile material, small tools, demos, games, and operations checks. It should not contain production secrets, credentials, private customer data, or private FLLC business logic.

## Reporting

For security concerns, use GitHub private vulnerability reporting when available or contact FLLC through https://fllc.net.

Do not include live credentials, private data, exploit traffic, or third-party personal information in public issues.

## Public-content boundary

Cybersecurity, OSINT, RF, and infrastructure material in this repository should remain lawful, defensive, educational, and source-backed.

Allowed public material includes defensive checklists, source maps, lab-safe explanations, engineering notes, benign demos, and verification scripts.

Do not submit malware, credential theft, persistence, stealth, evasion, unauthorized-access instructions, doxxing, or private data.
