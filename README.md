## 🎮 Play a Game — Right Here

> Real games. Real code. Clone it and play.

```bash
git clone https://github.com/Personfu/Personfu
cd Personfu
python3 -m games          # launches the arcade
```

| Game | Theme | Controls | Engine |
|------|-------|----------|--------|
| 🪱 **NET WORM** | a self-propagating worm crawling the subnet | arrows / `WASD` · `q` quit | [`games/snake.py`](games/snake.py) |
| 🛰️ **THREAT HUNT** | sweep a subnet for planted APT implants | `space` scan · `f` flag · `q` quit | [`games/minesweeper.py`](games/minesweeper.py) |

Zero dependencies — Python standard library only. Each game splits a pure,
unit-tested engine from a thin curses front-end. **25 tests**, run with `pytest`.
→ [arcade details](games/README.md)

**Don't want to clone?** Scroll down and play **THREAT HUNT right in your browser** ⬇️ —
one click per move, no install.

### 🛰️ ...and a tower defense that runs in your README

Generated by [`generate_tower_defense.py`](generate_tower_defense.py) — **720
lines of pure SMIL + CSS, zero JavaScript.** Enemies path the grid, towers fire
on the nearest waypoint, HUD tracks the waves.
