## 🎮 Play a Game — Right Here

> This profile ships **real, runnable Python games**. No "view source" required —
> clone the repo and play from your terminal.

```bash
git clone https://github.com/Personfu/Personfu
cd Personfu
python3 -m games          # 🕹️  launches the arcade menu
```

| Game | How to play | Engine |
|------|-------------|--------|
| 🐍 **Snake** | arrows / `WASD` · `q` quits | pure logic in [`games/snake.py`](games/snake.py) |
| 💣 **Minesweeper** | `space` reveal · `f` flag · `q` quit | first-click-safe board in [`games/minesweeper.py`](games/minesweeper.py) |

Zero dependencies — just the Python standard library. Every game splits a
**pure, unit-tested rules engine** from a thin curses front-end, with a
[15-test pytest suite](tests/) you can run with `pytest`. → [Arcade details](games/README.md)

### 🛰️ ...and a tower defense that runs in your README

The SVG below is generated by [`generate_tower_defense.py`](generate_tower_defense.py)
— **720 lines of pure SMIL + CSS, no JavaScript.** Enemies path via `<animateMotion>`,
towers fire on the nearest waypoint, and a live HUD tracks waves and base health.
