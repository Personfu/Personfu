## Repository policy

Not every repository under this account is a product. The account contains public showcases, private workbenches, forks, experiments, coursework, and security references.

FLLC uses this classification model:

- **Free showcase** — safe public education, engineering proof, reports, OSINT references, and portfolio artifacts.
- **Paid/member content** — public preview on fllc.net; deeper workflows, hosted modules, and custom reports stay behind member or client access.
- **Keep private** — production source, client-like material, raw reports, deployment details, business systems, and unfinished internal products.
- **No action / de-emphasize** — forks, offensive-tool references, thin experiments, and material that should not be marketed as FLLC software.

See the live governance page: https://fllc.net/github-portfolio
