## FLLC / Personfu

I build public-facing cybersecurity education, OSINT research systems, near-space telemetry dashboards, hardware lab documentation, and interactive web experiences under the FLLC brand.

The current standard is simple: make the work useful, visual, source-backed, and honest. Original builds are labeled as original. Forks and mirrors are labeled as references. Security content is framed for authorized labs, defensive analysis, and public-safe education.

## Production lanes

| Lane | What it is | Status |
|---|---|---|
| **FLLC.net** | Main business surface for services, subscriptions, tools, public writing, and member paths | Production |
| **NASA ASCEND** | High-altitude balloon website, telemetry storytelling, payload documentation, student engineering support | Active showcase |
| **CyberFlipper** | Flipper Zero / HackRF / SDR / embedded hardware education and workbench documentation | Public lab |
| **GovINT** | Public-source government, infrastructure, cyber, and geopolitical research dashboard | FLLC routed |
| **CyberWorld** | Browser-based cyberpunk training universe for simulations, missions, and security concepts | Showcase |
| **PERSONBOT** | Discord intelligence routing, source clustering, content drafting, and community automation | Private ops |

## Visual engineering standard

The next generation of FLLC pages should feel like working interfaces, not static brochures.

| Tier | System | Intended use |
|---|---|---|
| **S** | CesiumJS / 3D Tiles | Geospatial intelligence, telemetry paths, orbital/flight-style timelines |
| **S** | Three.js / WebGL / WebGPU | Hardware models, mission globes, threat-map visualizations, immersive dashboards |
| **A** | D3 + interactive SVG | Schematics, GPIO pinouts, signal paths, dependency maps, OSINT graph views |
| **A** | Next.js + TypeScript | Production UI, account flows, tools, subscriptions, dashboards |
| **B** | Data grids + Prism | CVE tables, code cards, config reviews, reports, evidence packs |

## Public operating boundary

I publish educational and defensive material for owned systems, classroom labs, CTF ranges, client-approved scopes, and public-source research. I do not present unauthorized access, credential theft, stealth, persistence, live-target exploitation, or individual tracking as public deliverables.

Capability is only valuable when it can survive review.
