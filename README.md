## Experience and focus

- **Defensive security and enterprise operations:** endpoint visibility,
  vulnerability management, IAM, incident workflows, source validation, and
  NIST/CIS-aligned practices.
- **Software and systems engineering:** small services, data pipelines,
  automation, visualization, and documentation that explains how the system
  behaves—not just how to start it.
- **Near-space and embedded engineering:** sensor firmware, PCB work, telemetry,
  simulation, and recovery-minded design through NASA ASCEND projects.
- **Public-source research:** OSINT, geospatial investigation, threat
  intelligence, and evidence trails with explicit coverage limits.
- **Education:** approachable labs, games, coursework, and field notes that turn
  large technical domains into a path someone can actually follow.

Security material is for defensive learning and authorized validation. A public
repository, bookmark, or research note is not permission to test a system.

## CyberEngineering path

The material is organized as a staged route through the work, with four
plain-language stops:

1. **Foundations — MERCURY:** operating systems, networking, teams, and core
   tools. [Start with the foundations guide →](https://github.com/Personfu/CyberEngineering/blob/main/foundations/README.md)
2. **Mission atlas — HELIOS:** 150 mission-oriented cyberengineering prompts
   across software, hardware, cloud, AI, OT, space, response, and governance.
   [Open the atlas →](https://github.com/Personfu/CyberEngineering/tree/main/atlas)
3. **Assessment flightbook:** engagement planning, written scope, evidence, and
   reviewable assessment work.
   [Open assessments →](https://github.com/Personfu/CyberEngineering/blob/main/assessment/README.md)
4. **Research:** source-backed dossiers, methods, limitations, and next
   questions. [Open research →](https://github.com/Personfu/CyberEngineering/blob/main/research/README.md)

For the complete route, use the
[`CyberEngineering` index](https://github.com/Personfu/CyberEngineering/blob/main/INDEX.md)
and verify claims against its
[`SOURCES.md`](https://github.com/Personfu/CyberEngineering/blob/main/SOURCES.md).
